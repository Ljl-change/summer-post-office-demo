# 夏末的邮局

一个可直接游玩的治愈系剧情探索小游戏 Demo。你将在夏日傍晚回到海风镇，替即将关门的老邮局送出四封迟到的信，并在一段段重逢里准备好前往远方。

## 在线游玩

[打开《夏末的邮局》](https://ljl-change.github.io/summer-post-office-demo/)

## 操作方式

- `WASD` 或方向键：移动角色
- 靠近互动点后按 `E`：互动
- 点击金色微光旁的物品名称：直接互动
- 左下角：小镇地图
- 右下角：邮差包 / 背包

## 包含内容

- 角色创建与本地存档
- 六个小镇场景：老邮局、海边街道、杂货店、老车站、灯塔、海滩
- 四封旧信主线与轻解谜
- NPC 对话、选择、背包、任务和地图
- 隐藏互动与普通 / 隐藏结局
- 原创夏日海边场景插画、场景加载过渡与互动微光引导

## 本地运行

这是一个静态网页项目。克隆仓库后，直接用浏览器打开 `index.html` 即可；也可以用任意静态文件服务器预览。

```text
index.html
assets/       场景背景资源
README.md
```

## 部署

项目通过 GitHub Pages 从 `main` 分支根目录发布。
